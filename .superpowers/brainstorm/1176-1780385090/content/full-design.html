Key design decisions:
• ⟡ command — purple accent glyph + pink command verb as header on every screen
• Score bars — 5-block bar (█████) colored green/amber/gray by relative rank
• Live index counter — single line updates in-place with file count + current filename
• Setup steps — [n/4] in gray, step name in bold white, ✓ result lines indented below
